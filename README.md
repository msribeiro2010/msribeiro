# MarceloRibeiro — portfólio

Site pessoal de Marcelo S. Ribeiro, desenvolvedor full-stack especializado em inteligência artificial.

Página estática para o GitHub Pages: `index.html`, `style.css` e `script.js`. Sem etapa de build.

## Seções

- Início, com o retrato em `photo.jpg`
- Sobre, com as competências
- Serviços
- Contato, com formulário (EmailJS) e links diretos

## Como ver localmente

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático. Os caminhos são relativos, então funcionam na raiz do projeto e em `https://msribeiro2010.github.io/msribeiro/`.

## Formulário

O envio usa EmailJS. As chaves públicas estão em `script.js`. O guia em `EMAIL_SETUP.md` descreve a conta e o template.
